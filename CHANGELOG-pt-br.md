# Changelog

[English](CHANGELOG.md) | **Português (Brasil)**

## v2.10.34

### Adicionado

- Adicionada a localização em inglês para a extensão, mantendo o português do Brasil como idioma disponível.
- Para trocar o idioma, abra a Command Palette com `Ctrl+Shift+P`, execute **Configure Display Language**, escolha `en` para inglês ou `pt-br` para português (Brasil) e recarregue o VS Code.
